# 🎵 Spotify Clone

A responsive **Spotify-inspired music player** built using **HTML, CSS, and JavaScript**.
This project focuses on recreating the core music-player experience with album browsing, song playback, controls, and a responsive UI.

## 🚀 Features

* 🎧 Album-based music browsing
* ▶️ Play / Pause songs
* ⏭️ Next & Previous song controls
* 🔊 Volume control & Mute
* ⏱️ Song duration and progress bar
* 📱 Responsive design
* 🎨 Spotify-inspired UI
* 📂 Local audio files and album artwork
* 🌐 Netlify deployment compatible

## 🛠️ Tech Stack

* HTML5
* CSS3
* JavaScript
* HTML5 Audio API
* Netlify


## ⚙️ How It Works

The application uses JavaScript to manage albums and songs and the **HTML5 Audio API** for music playback.

Album information is loaded from `info.json`, while the song list is maintained in JavaScript for compatibility with static hosting platforms such as Netlify.
